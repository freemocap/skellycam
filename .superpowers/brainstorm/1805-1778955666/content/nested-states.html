How should nested substates within Streaming be displayed?

Both machines have substates inside Streaming — the Camera has 5 frame-level states, the CameraGroup has 3 parallel regions

A

Expand In-Place

When the stepper reaches Streaming, the card expands downward to reveal the substates as a nested mini-flow. The top-level flow stays visible above. Feels like "zooming in" on the active state.

Disconnected → Enumerated → Configured → ┌ Streaming ────────────────────────┐
│ WaitingForFrame → FrameAvailable →│
│ AtBarrier → Capturing → Sending │
└───────────────────────────────────┘ → ShuttingDown
B

Two-Level Stepper

The top-level flow stays in one row. A second row below shows the substates of the currently selected top-level state. When Streaming is active, the substate row animates through the frame cycle.

Top-level: Disconnected → Enumerated → Configured → Streaming → ShuttingDown
Substates: WaitingForFrame → FrameAvailable → AtBarrier → Capturing → Sending
C

Tabbed Detail Panel

Top-level states shown as a compact flow. Clicking any state shows its substates and transitions in a detail panel below. More of an explorer feel — hover to see connections, click to drill in.

Disconnected → Enumerated → Configured → [Streaming ▼] → ShuttingDown
Streaming substates:
WaitingForFrame → FrameAvailable → AtBarrier → Capturing → Sending ↺
From any: shutdown → ShuttingDown
