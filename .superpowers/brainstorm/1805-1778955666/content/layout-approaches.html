How should the state machine visualization work?

Pick the interaction model that feels most useful — each has a different strength

A

Interactive Stepper

States laid out left-to-right as connected cards. Click event buttons to advance through the lifecycle. Current state pulses green. Transition log builds up below. Best for learning the lifecycle flow and stepping through transitions one at a time.

B

Full Graph Diagram

Every state and transition visible at once as an interactive node graph. Click any transition arrow to fire it. Current state highlights, error paths shown in red. Resembles the Mermaid diagram but clickable. Best for seeing the complete architecture at a glance.

C

Both — Stepper + Diagram

Stepper on top for interactive walkthrough, full Mermaid diagram below for reference. The stepper drives the XState machine; the diagram is static reference rendered by mermaid.js. Best of both — interactive learning + complete reference in one page.
