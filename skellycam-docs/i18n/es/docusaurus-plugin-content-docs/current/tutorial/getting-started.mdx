# Primeros Pasos

## Requisitos Previos

- **Python 3.11+** (se recomienda 3.12) — [python.org/downloads](https://www.python.org/downloads/)
- **uv** — Gestor rapido de paquetes Python: [astral.sh/uv](https://github.com/astral-sh/uv)
- **Node.js 18+** — Necesario para la interfaz React/Electron: [nodejs.org](https://nodejs.org/)
- **Camaras USB o camaras web integradas**

## Instalacion del Servidor Python

```bash
git clone https://github.com/freemocap/skellycam
cd skellycam
uv venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
uv sync
```

Para instalar las dependencias de desarrollo (pytest, ruff, etc.):

```bash
uv sync --group dev
```

### Dependencias Especificas de Linux

La grabacion de audio en Linux requiere paquetes adicionales del sistema:

```bash
sudo apt update
sudo apt install clang portaudio19-dev
```

## Instalacion de la Interfaz Frontend

```bash
cd skellycam-ui
npm install
```

## Ejecutando SkellyCam

### Paso 1: Iniciar el Servidor Python

```bash
python -m skellycam
```

Despues de instalar con `uv sync`, tambien puedes usar el comando `skellycam` directamente:

```bash
skellycam
```

El servidor se inicia en `http://localhost:53117`. Puedes verificar que esta en ejecucion visitando `http://localhost:53117/health` en tu navegador — deberias ver `"Hello"`.

La documentacion interactiva de la API Swagger esta en `http://localhost:53117/docs`.

### Paso 2: Iniciar la Interfaz (Modo de Desarrollo)

En una terminal separada:

```bash
cd skellycam-ui
npm run dev
```

Esto lanza el servidor de desarrollo Vite. Si se ejecuta dentro de Electron, lanza la ventana de Electron; de lo contrario, abre la URL que aparece en la terminal.

## Flujo de Trabajo de la Primera Sesion

1. **Detectar camaras** — La interfaz o una llamada a `POST /skellycam/camera/detect` busca las camaras USB disponibles.
2. **Crear grupo de camaras** — Selecciona las camaras y configura resolucion/velocidad de fotogramas/exposicion a traves de la interfaz o `POST /skellycam/camera/group/apply`.
3. **Vista previa en vivo** — La conexion WebSocket transmite fotogramas a la interfaz en tiempo real.
4. **Grabar** — Haz clic en grabar o `POST /skellycam/camera/group/all/record/start` para comenzar la grabacion. Opcionalmente, selecciona un microfono para capturar audio junto con el video. Detener con el boton de parada o `GET /skellycam/camera/group/all/record/stop`.
5. **Revisar** — Las grabaciones se guardan en `~/skellycam_data/recordings/` con archivos de video sincronizados y CSVs de marcas de tiempo. Usa la pagina de Reproduccion para revisar las grabaciones con reproduccion multivideo bloqueada por fotograma — todos los videos siempre muestran el mismo numero de fotograma.

## Verificacion de la Instalacion

Ejecuta el conjunto de pruebas para confirmar que todo esta correctamente configurado:

```bash
uv run pytest skellycam/tests/ -v
```

Todas las pruebas deberian pasar sin requerir camaras fisicas — el conjunto de pruebas usa mocks y un cliente de pruebas ligero de FastAPI.

## Solucion de Problemas

**Puerto 53117 ya en uso** — SkellyCam automaticamente termina cualquier proceso existente en el puerto 53117 al iniciar. Si esto falla, detiene manualmente el proceso en conflicto o cambia el puerto en `skellycam/api/server_constants.py`.

**No se detectan camaras** — Verifica que tus camaras USB estan conectadas y reconocidas por el sistema operativo. En Linux, asegurate de que tu usuario tiene permisos para acceder a los dispositivos `/dev/video*` (puede que necesites agregar tu usuario al grupo `video`: `sudo usermod -aG video $USER`).

**El audio no funciona en Linux** — Asegurate de haber instalado los paquetes del sistema: `sudo apt install clang portaudio19-dev`.
