# بداية سريعة

هالدليل رح يمشيك خطوة بخطوة لتسجيل أول جلسة متزامنة متعددة الكاميرات بخمس خطوات.

:::note لقطة شاشة قريباً
لقطة شاشة لنافذة تطبيق SkellyCam عند أول تشغيل، بتبيّن الواجهة الرئيسية مع كشف الكاميرات وأزرار التسجيل.
:::

## 1. ثبّت SkellyCam

حمّل وثبّت SkellyCam من [صفحة التحميل](/download). شغّل المثبّت لنظامك — ما بتحتاج تبعيات إضافية.

:::tip مطوّر من قبل؟
كمان فيك [تشغّل من الكود المصدري](/docs/development/).
:::

## 2. شغّل التطبيق

افتح SkellyCam بعد التثبيت. السيرفر بيشتغل تلقائياً بالخلفية وواجهة المستخدم بتفتح بنافذة التطبيق.

## 3. وصّل واكشف الكاميرات

وصّل كاميرات الـ USB تبعك (أو استخدم كاميرا اللابتوب المدمجة). بالواجهة، اضغط **اكشف الكاميرات** لمسح الأجهزة المتوفرة. SkellyCam رح يعرض كل الكاميرات المكتشفة.

اختار الكاميرات اللي بدك تستخدمها واضغط **تطبيق** لإنشاء مجموعة كاميرات. رح تشوف معاينة مباشرة من كل كاميرا.

:::tip API
كشف الكاميرات متوفر كمان عبر `POST /skellycam/camera/detect`. شوف [مرجع الـ API](/docs/technical/api-reference) للتفاصيل.
:::

## 4. سجّل

اضغط **تسجيل** لبدء التسجيل. كل الكاميرات رح تلتقط فيديو متزامن — كل كاميرا بتنتج نفس العدد بالضبط من الإطارات.

اختيارياً، اختار ميكروفون لتسجيل الصوت مع الفيديو.

اضغط **إيقاف** لما تخلص.

:::tip API
بدء التسجيل: [`POST /skellycam/camera/group/all/record/start`](/docs/technical/api-reference#post-skellycamcameragroupallrecordstart)
إيقاف التسجيل: [`GET /skellycam/camera/group/all/record/stop`](/docs/technical/api-reference#get-skellycamcameragroupallrecordstop)
:::

## 5. شوف التسجيل

روح لصفحة **التسجيلات** بالواجهة. تسجيلك رح يظهر بالقائمة مع بيانات وصفية (عدد الكاميرات، المدة، الـ FPS، عدد الإطارات).

اختار تسجيل لفتح عارض **التشغيل**. كل الفيديوهات بتتشغل بقفل الإطارات — كل كاميرا دايماً بتعرض نفس رقم الإطار، بدون انزلاق.

:::tip API
عرض التسجيلات: `GET /skellycam/playback/recordings`
تحميل تسجيل: `POST /skellycam/playback/load`
:::
