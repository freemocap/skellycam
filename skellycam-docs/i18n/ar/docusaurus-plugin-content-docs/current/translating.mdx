# ترجمة SkellyCam

نستخدم ترجمات المجتمع لجعل التقاط الحركة متاحاً في جميع أنحاء العالم. لا حاجة للبرمجة — فقط عدّل ملف JSON وافتح طلب سحب.

**[تصفح ملفات الترجمة على GitHub](https://github.com/freemocap/skellycam/tree/development/skellycam-ui/src/i18n/locales)**

## الحالة الحالية

جميع الترجمات غير الإنجليزية **مُولدة بالذكاء الاصطناعي وغير مراجعة** — من شبه المؤكد أنها تحتوي على أخطاء. حتى إصلاح بضع سلاسل نصية يساعد!

## ملفات الترجمة

جميع سلاسل واجهة المستخدم موجودة في `skellycam-ui/src/i18n/locales/`. الإنجليزية (`en-english.json`) هي المصدر المرجعي. جميع اللغات الأخرى مُولدة بالذكاء الاصطناعي وتنتظر مراجعة المجتمع.

المدعومة حالياً: الإنجليزية، الإسبانية، الفرنسية، الألمانية، الإيطالية، البرتغالية (البرازيل)، الكتالونية، الهولندية، السويدية، البولندية، التشيكية، الرومانية، المجرية، اليونانية، الكرواتية، الصربية، الأوكرانية، الروسية، الجورجية، التركية، العربية، الفارسية، الأردية، الهندية، البنغالية، التاميلية، النيبالية، السنهالية، الصينية (المبسطة)، اليابانية، الكورية، التايلاندية، الفيتنامية، الإندونيسية، الملايو، التاغالوغ، البورمية، السواحيلية، والأمهرية.

## كيفية المساهمة

1. انقر على أي ملف لغة أعلاه (أو ابحث عنه في `skellycam-ui/src/i18n/locales/`)
2. انقر على أيقونة القلم للتعديل مباشرة على GitHub
3. أصلح أي ترجمات تراها خاطئة أو غير طبيعية
4. قدّم طلب سحب

تستخدم السلاسل النصية تنسيق i18next — احتفظ بـ `{{variables}}` كما هي تماماً واحتفظ بلواحق `_one`/`_other` للجمع.

سلاسل الواجهة الخلفية (أسماء الكاميرات، رسائل السجل، برامج الترميز، مسارات الملفات) لا تحتاج ترجمة.

## إضافة لغة جديدة

1. انسخ `en-english.json` إلى `<locale-code>-<language-name>.json`
2. ترجم القيم (وليس المفاتيح)
3. عيّن `_meta.translationSource` إلى `"ai-generated"` أو `"human-authored"`
4. افتح مشكلة أو طلب سحب — سنربطها بالتطبيق
