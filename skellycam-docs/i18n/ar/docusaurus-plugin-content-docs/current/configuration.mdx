# الإعدادات

## إعدادات الخادم

يتم تعريف تكوين شبكة الخادم في `skellycam/api/server_constants.py`:

```python
PROTOCOL = "http"
HOSTNAME = "localhost"
PORT = 53117
APP_URL = f"{PROTOCOL}://{HOSTNAME}:{PORT}"
```

لتغيير منفذ الخادم، عدّل `PORT` قبل تشغيل الخادم. يجب تكوين واجهة المستخدم الأمامية للاتصال بنفس المضيف والمنفذ.

## تكوين الكاميرا

لكل كاميرا في المجموعة `CameraConfig` خاص بها مع الإعدادات التالية:

| Setting | Type | Default | الوصف |
|---------|------|---------|-------------|
| `camera_id` | `str` | `"000"` | معرّف فريد للكاميرا |
| `resolution` | `object` | `{"width": 1280, "height": 720}` | دقة الالتقاط بالبكسل |
| `framerate` | `float` | `-1` | معدل الإطارات المستهدف (`-1` يستخدم الافتراضي للكاميرا) |
| `exposure` | `int` | `-7` | قيمة تعريض الكاميرا (تعتمد على العتاد) |
| `exposure_mode` | `str` | `"MANUAL"` | وضع التعريض: `MANUAL`، `AUTO`، أو `RECOMMENDED` |
| `rotation` | `int` | `-1` | دوران الصورة (انظر الجدول أدناه) |
| `capture_fourcc` | `str` | `"MJPG"` | كود FOURCC لترميز الالتقاط |
| `writer_fourcc` | `str` | `"X264"` | كود FOURCC لترميز التسجيل |

يتم تطبيق تكوين الكاميرا عبر نقطة نهاية `POST /skellycam/camera/group/apply` أو من خلال لوحة تكوين الكاميرا في واجهة المستخدم.

### الدقة

تُحدد الدقة ككائن متداخل مع حقلي `width` و `height`:

```json
{
  "resolution": { "width": 1280, "height": 720 }
}
```

قد لا تتطابق الدقة المطلوبة مع الدقة الفعلية إذا كانت الكاميرا لا تدعمها. سيعود OpenCV بصمت إلى أقرب دقة مدعومة. يتم الإبلاغ عن الدقة الفعلية في الاستجابة.

### معدل الإطارات

اضبط `framerate` على `-1` (الافتراضي) لاستخدام معدل الإطارات الأصلي للكاميرا وتشغيل حلقة الإطارات بأقصى سرعة يسمح بها العتاد. اضبط قيمة موجبة (مثل `30`) لاستهداف معدل التقاط محدد.

### التعريض

قيم التعريض تعتمد على العتاد. تستخدم كاميرات USB الشائعة قيمًا صحيحة سالبة (مثل -5، -7، -10) حيث تعني القيمة الأكثر سلبية وقت تعريض أقصر. يعتمد النطاق الصالح على طراز الكاميرا.

### الدوران

يُطبق الدوران برمجيًا بعد التقاط الإطار. تتوافق القيم مع أكواد `cv2.rotate()` في OpenCV:

| Value | الدوران |
|-------|----------|
| `-1` | بدون دوران (افتراضي) |
| `0` | 90 درجة باتجاه عقارب الساعة |
| `1` | 180 درجة |
| `2` | 90 درجة عكس عقارب الساعة |

## مجلدات البيانات

تُخزن جميع بيانات SkellyCam تحت `~/skellycam_data/` افتراضيًا. يتم تعريف هذا المجلد الأساسي في `skellycam/system/default_paths.py`.

### هيكل المجلدات

```
~/skellycam_data/
├── recordings/
│   └── 2024-09-15T14_30_00/          # One folder per recording session
│       ├── 2024-09-15T14_30_00_info.json   # Recording metadata
│       └── synchronized_videos/
│           ├── *.camera0.mp4               # Video file per camera
│           ├── *.camera1.mp4
│           └── timestamps/
│               ├── *_timestamps.csv        # Multi-frame timestamps
│               ├── *_stats.txt             # Human-readable statistics
│               ├── *_stats.json            # Machine-readable statistics
│               └── camera_timestamps/
│                   ├── *.camera0.timestamps.csv
│                   └── *.camera1.timestamps.csv
├── logs_info_and_settings/
│   └── logs/
│       └── log_*.log                       # Timestamped log files
├── telemetry_config.json                   # Telemetry opt-in/opt-out
└── telemetry_uid                           # Anonymous user ID for telemetry
```

### بيانات التسجيل الوصفية

يحتوي ملف `_info.json` على تكوين التسجيل بما في ذلك إعدادات الكاميرا، واسم التسجيل، والمعرّف الفريد UUID، وطابع البدء الزمني.

### ملفات CSV للطوابع الزمنية

تحتوي ملفات الطوابع الزمنية لكل كاميرا على صف واحد لكل إطار مع طوابع زمنية عالية الدقة `perf_counter_ns` في كل مرحلة من دورة الحياة. يحتوي ملف الطوابع الزمنية متعدد الإطارات على بيانات مزامنة بين الكاميرات.

## التسجيل

يستخدم SkellyCam مكتبة [skellylogs](https://github.com/freemocap/skellylogs) للتسجيل، والتي توفر مستويات تسجيل مخصصة وتوجيه السجلات عبر WebSocket. يتم ضبط مستوى التسجيل في `skellycam/__init__.py`:

```python
LOG_LEVEL = LogLevels.TRACE  # Change to LogLevels.INFO for less verbose output
```

يتم توجيه السجلات بمستوى `TRACE` وأعلى إلى عملاء WebSocket المتصلين لعرضها في طرفية السجلات في واجهة المستخدم.

لمزيد من التفاصيل حول مستويات التسجيل والمعالجات وخيارات التكوين، انظر [مستودع skellylogs](https://github.com/freemocap/skellylogs).

## القياس عن بُعد

يجمع SkellyCam بيانات استخدام مجهولة للقياس عن بُعد لمساعدة فريق التطوير على فهم كيفية استخدام البرنامج. تتم إدارة القياس عن بُعد بواسطة حزمة [skellypings](https://github.com/freemocap/skellypings).

### ما يتم جمعه

يُرسل حدث `app_opened` عند بدء التشغيل يحتوي على مواصفات النظام المجهولة: اسم وإصدار نظام التشغيل، وبنية المعالج، وعدد وحدات المعالجة (الفعلية والمنطقية)، وإجمالي ذاكرة الوصول العشوائي، وإصدار Python. لا يتم جمع أي بيانات كاميرا أو تسجيلات أو معلومات شخصية.

### إلغاء الاشتراك

القياس عن بُعد مُفعّل افتراضيًا. لتعطيله، عدّل `~/skellycam_data/telemetry_config.json`:

```json
{
  "telemetry_enabled": false
}
```

يمكنك أيضًا تبديل القياس عن بُعد من صفحة الإعدادات في واجهة المستخدم. يسري الإعداد عند بدء تشغيل الخادم التالي.
